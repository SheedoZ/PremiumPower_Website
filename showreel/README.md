# Premium Power — 30-second showreel

`premium-power-showreel.mp4`: 30 s, 1920×1080, 60 fps, H.264 + AAC 320 kb/s,
loudness −14 LUFS, true peak under −1 dBTP. Every frame and every sound is
generated by the code in `src/`; the only inputs are the logo, the gallery
photos and the copy from this website.

## Rebuild

Needs Node 18+, Playwright with Chromium, Python 3 and curl.

```bash
bash showreel/fetch-tools.sh      # static ffmpeg + fonts into showreel/.cache
node showreel/render.cjs          # writes showreel/premium-power-showreel.mp4 (~8 min)
```

Other modes: `--stills 1.5,6.2` (PNG frames), `--from 5 --to 9` (a clip),
`--audio-only`. To preview in a browser, serve the repository root
(`python -m http.server`) and open `/showreel/src/index.html`.

## Files

- `src/cues.js` — the one timeline both picture and sound read.
- `src/scenes.js` — the shots; `render(ctx, t)` draws any moment on its own.
- `src/city.js` — the Cairo skyline and its lights.
- `src/assets.js` — keys the logo and gallery photos off their white backgrounds.
- `src/core.js` — easing, text layout, glow, grain, glitch.
- `src/audio.js` — score and sound design (Web Audio, no samples).
- `render.cjs` — runs the page in headless Chromium, averages four samples per
  frame for motion blur and pipes the frames into ffmpeg.

Type: League Gothic (in place of the site's Bebas Neue), Inter (in place of
Outfit), JetBrains Mono and IBM Plex Sans Arabic, all under the SIL Open Font
License.
